# Котики Маги 3D — сервер

Сервер соединяет игроков, хранит аккаунты, друзей и переписку,
а заодно раздаёт саму игру.

## В интернете

1. Залейте содержимое этой папки в репозиторий на GitHub.
2. На render.com: **New + → Blueprint**, выберите репозиторий.
3. Render прочитает `render.yaml` и сам создаст сервер и базу данных.
4. Получится адрес вида `имя.onrender.com` — по нему открывается
   и игра, и сервер.

## Дома

```
python server.py
```

Откроется на http://localhost:8765/ , данные лягут в server_data.json.

Личные данные сюда не попадают — так задано в .gitignore.
